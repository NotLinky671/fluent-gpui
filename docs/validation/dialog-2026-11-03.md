## 修改前 → 修改后（可观察行为）

- 组件库：无 `Dialog`/`AlertDialog` → `fluent_ui::Dialog` / `fluent_ui::AlertDialog` 可用：
  Fluent scrim + 居中卡片 + 标题/正文/footer，受控与非受控两种开关，打开移入焦点、
  Tab 约束在卡片内、关闭归还焦点；Esc/scrim 按 `Cancel` 请求关闭（可否决），Enter 按 `Confirm`；

  模态对话框（scrim 遮挡背景、焦点陷阱、Esc/scrim 语义化）。`pending` 状态机与既有测试语义不变。

## gpui-base 缺口与本组件补齐

- base `Dialog` 不记忆旧焦点：wrapper 用 window keyed state 在打开首帧记录
  `window.focused`、聚焦宿主，在关闭首帧于焦点仍在对话框内时归还（与 Popover 同形）。
- base 宿主自带 `focus_trap`；Tab 约束依赖 `FluentRoot` 的 `advance_focus`（已存在）。
- 关闭帧才归还焦点：若调用方在关闭的同一帧卸载对话框元素，归还不会发生。
  notes 应用因此让两个对话框常驻挂载、以受控 `open` 驱动。
