# Sheet 侧边抽屉（T-047）

日期：2026-11-04。基线：HEAD `bdcf1b9`；工作区同时有 T-048（Tabs）的未提交改动，本次没有提交，验证是在包含该并行改动的同一工作区上完成的。

## 修改前 → 修改后（可观察行为）

- 组件库：无 Sheet → `fluent_ui::Sheet` 可用：四向（默认右侧）模态抽屉，Fluent scrim 与面板，受控/非受控开关，打开时滑入并把焦点移入，Esc 或 scrim 按下请求关闭，退出动画结束后归还焦点。
- **布局回归修复**：最初的实现只在打开时返回绝对定位的 `deferred` 宿主、关闭时返回空 `div()`。打开后父级 flex 少一个零高度 item 及其 gap，下方内容会上跳 12 逻辑像素（用户视频中 18 物理像素 @150%）。现在两种状态都保留同一个零高度在流占位，打开/关闭不再移动周围内容。
- **退出方向修复**：调用方（Gallery）在关闭时把 `side` 清成 `None`，组件回退到默认右侧，导致左/上/下抽屉关闭时从右侧滑出。现在 `side` 在打开时锁定，退出动画继续使用进入时的边缘；打开期间改 `side` 仍立即生效。
- **hover 穿透修复**：scrim 之前只有背景绘制，没有遮挡命中框，Sheet 打开后鼠标移到背后的按钮仍会触发 hover。现在 scrim `occlude()`，背后页面不再收到 hover 边沿；点击仍由宿主的 overlay 层处理。测试用真实的 `Button` 验证它保持 rest 填充，不会淡到 hover 填充。
- Gallery：新增 `sheet` 分区（四个方向的打开按钮 + 常驻挂载的受控 Sheet）和 `sheet-right-open` 像素夹具；Dialog/Menu/Tabs 等既有夹具不变。
- 没有改动便签应用；`docs/apps/notes.md` 只更新了“已实现、未接入”的状态与接入点。

## 设计与取舍

- **尺寸是组件常量**：Fluent 的 Drawer 尺寸不是主题 token；默认 320px（`small`），`Sheet::size` 可覆盖。左/右为宽、上/下为高；`max_w_full` / `max_h_full` 防止小窗口里挂到对侧边缘。内容超出时被裁剪，没有滚动区和拖拽关闭。
- **一个曲线驱动进出**：gpui-base 的 `Presence` 只用一条 `Transition`，因此选择对称的 `curveEasyEase`，而不是 Fluent 常见的 enter `curveDecelerateMid` / exit `curveAccelerateMid` 两条曲线。未与官方渲染核对。
- **反向缩短**：进场中途关闭时 `Presence` 按当前进度缩短反向时长，不会从 0 重新播完整退出；这是测试里“打开后立即关闭”会瞬间收起的来源。
- **模态层在帧末绘制**：gpui-base 的宿主只有 `anchored`，没有 `deferred`；wrapper 补上与 Dialog 相同的 `deferred`，否则放在滚动/裁剪容器里的 Sheet 会被祖先裁掉。行为测试用 400×300 的 `overflow_hidden` 容器验证 scrim 的绘制蒙版仍是整个窗口。
- **零高度在流占位**：`deferred` 宿主绝对定位、不参与父级 flex 布局；打开和关闭必须返回同样的零高度在流占位，否则打开时会丢掉一个 flex item 及其 gap，下方内容跳动。测试 `opening_does_not_shift_the_content_below` 锁定该承诺。
- **scrim 同时是遮挡层**：`occlude()` 让 scrim 成为 `BlockMouse` 命中框，背后页面不会收到 hover 或点击；只靠背景绘制会让 hover 穿过半透明遮罩。测试 `the_scrim_blocks_hover_on_the_page_behind` 锁定该行为。
- **退出方向锁定**：`side` 在打开时写入 keyed state，退出期间不随调用方清空/回退而改变；否则关闭左侧抽屉时面板会先跳到右侧再滑出。测试 `closing_keeps_the_edge_it_opened_from` 锁定该承诺。
- **焦点归还时机**：进入首帧记录 `window.focused` 并把焦点交给宿主句柄；退出期间继续被陷阱约束，等 `Presence` 报告 Absent 且焦点仍在抽屉内时才归还。调用方若在 `open(false)` 同帧卸载元素，归还不会发生——与 Dialog 相同的常驻挂载约束。
- **关闭原因**：gpui-base 宿主把 Esc 与 overlay 按下统一走 `request_close`，所以 `on_open_change` 只收到 `false`，没有 reason 参数；需要区分来源的调用方必须自己接键盘/指针。
- **无障碍**：面板设 `Role::Dialog`，但焦点在宿主 div 上；AccessKit 的模态语义与朗读顺序留给 T-049 审计。

| `sheet::tests::the_scrim_blocks_hover_on_the_page_behind` | Sheet 打开后把鼠标移到背后的 hover 探针上，探针不会收到 `true`；去掉 scrim 的 `occlude()` 后收到 `true` |
| `sheet::tests::a_button_behind_the_scrim_keeps_its_rest_fill` | 真实的 Secondary Button 在 scrim 下保持 rest 填充（l=1.0），不会变成 hover 填充（l≈0.961）；去掉 `occlude()` 后失败 |

| `sheet::tests::opening_does_not_shift_the_content_below` | 打开/关闭前后，Sheet 下方标记的 y 坐标保持不变；旧实现打开时会少一个 flex gap，标记上跳 12px |
| `sheet::tests::opening_does_not_shift_a_scrolled_page` | 页面滚到底部时打开/关闭 Sheet，标记的 y 坐标同样不变；覆盖 Gallery 中 Sheet 位于滚动内容里的场景 |

**像素证据**：`sheet-right-open` 夹具（460×300 逻辑像素、light、Windows 150% DPI）经 `window.render_to_image()` 生成，与基线逐像素比较通过；截图里右侧面板、左侧圆角、scrim、标题/正文/footer 均符合预期。

**定向破坏**：去掉 `deferred` 包装后 `the_modal_layer_escapes_a_clipped_parent` 失败（scrim 蒙版变成 400×300 容器）；去掉零高度在流占位后两条布局测试失败（未滚动页面打开时标记上跳 12px，滚到底部的页面关闭时标记偏移 12px）；去掉 `side` 锁定后 `closing_keeps_the_edge_it_opened_from` 失败（左侧退出中面板出现在 x≈664）；去掉 scrim 的 `occlude()` 后两条 hover 测试失败（探针收到 `true`，Button 画成 hover 填充 l≈0.961）。恢复后均通过。
