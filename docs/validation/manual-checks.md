# 人工验证清单

日期：2026-11-06。对应基线：`a36318d`。

这些项目**只能人工在真窗口里做**：它们依赖真实的指针事件顺序、窗口边缘、DPI 缩放和
肉眼判断，自动化测试（GPUI 行为测试、像素基线）覆盖不到。每项都写了"怎么操作"、
"应该看到什么"和"看到什么算错"。

## 怎么启动

```bash
cargo run -p fluent-gallery                 # 组件图库
FLUENT_GALLERY_SECTION=tabs cargo run -p fluent-gallery   # 只看某个分区
FLUENT_GALLERY_APPEARANCE=dark cargo run -p fluent-gallery
FLUENT_GALLERY_APPEARANCE=high-contrast cargo run -p fluent-gallery
cargo run -p fluent-notes                   # 便签应用
```

可用分区：`buttons` `dialog` `feedback` `fields` `inputs` `misc` `selection` `sheet`
`switch` `tabs` `textareas`。菜单与 Popover 在 `misc`。

---

## 1. 菜单淡入（`misc`）

- **操作**：点开菜单，盯着面板出现的第一瞬间。
- **期望**：面板一出现就是最终尺寸，只有透明度渐入（约 350ms，先快后慢），并伴随约 4px 下移；关闭是瞬时的。
- **算错**：看到高度从 0 展开、宽度变化、或先出现再跳位。

## 2. 菜单单层表面（`misc`）

- **操作**：打开菜单，看边缘与阴影。
- **期望**：一层卡片、一套圆角、一套阴影。
- **算错**：双层阴影、"卡片套卡片"、圆角重影。

## 3. 无图标行的缩进（`misc`）——**待你决定，不是 bug**

- **现状**：没有图标的行文字比标题（如 "Actions"）内缩约 16px，保留了导引槽。
- **官方行为**：整组都没有图标时不留这个槽。
- **需要你回答**：改成对齐标题，还是保持现状？改了会影响你已经看过的菜单外观。

## 4. 子菜单（`misc` 或便签的菜单）

- **操作**：鼠标停在带右箭头的行上 300ms；或按 `→` / `Enter`。
- **期望**：
  - 子面板贴着该行**右边缘**出现，顶边与该行对齐；
  - 指针从父行移进子面板**不关闭**；
  - 指针移到同一层的另一行，子面板关闭；
  - `Esc` 退一层、再按一次关整个菜单；`Tab` 一次关整条链；
  - 窗口右侧空间不足时，子面板翻到该行**左侧**。
- **算错**：子面板出现在菜单左上角或原点（首帧没测到边界）、点进子面板根菜单就关、悬停时反复开关闪烁、`Tab` 只关了子菜单。

## 5. Tooltip

- **操作**：鼠标停在图标按钮上停留、移开；再把窗口缩到很矮，停在靠底部的按钮上。
- **期望**：锚在触发器上方/下方、间隙 4px；移开立即消失；靠底部时翻到上方。
- **未验证且需要你试**：键盘聚焦触发是否显示、页面滚动时 tooltip 是否跟随。
- **算错**：tooltip 出现在鼠标位置而不是触发器旁、移开后残留、翻转位置压住触发器。

## 6. Tabs（`tabs`）

- **操作**：依次点击不同标签；用方向键与 Home/End；尝试点禁用标签。
- **期望**：指示条从旧位置**滑**到新位置，宽度同步变化（右边缘不跳）；聚焦时选中项有 2px 内描边；禁用标签点不动、方向键跳过。
- **算错**：右边缘先跳一下再滑动（这是修过的 bug，要确认真的没了）、点击后选中不变、指示条停在两标签之间。

## 7. Sheet（`sheet`）

- **操作**：打开、关闭侧边抽屉。
- **期望**：从侧边滑入滑出；关闭动画**结束后**焦点回到触发按钮；抽屉内按钮可点。
- **算错**：关闭瞬间焦点丢失、关闭导致页面内容跳动、抽屉被裁切。

## 8. Dialog（`dialog`）

- **操作**：打开对话框，看它**下方**的内容。
- **期望**：打开/关闭时页面**不位移**；`Cancel` 有 1px 边框；Esc 关闭。
- **算错**：打开瞬间下方内容上下跳一下（这是修过的 bug）。

## 9. 主题与缩放

- **操作**：`FLUENT_GALLERY_APPEARANCE=dark` 与 `high-contrast` 各过一遍第 1–8 项；系统缩放 100% 与 150% 各看一次。
- **期望**：文字对比度足够、禁用态仍可辨认、危险项是红色、scrim 足够暗、1px 分隔线在 150% 下不发虚。
- **算错**：深色下文字看不清、高对比下边框消失、150% 下指示条粗细变成 1px 或 3px。

## 10. 便签应用（`cargo run -p fluent-notes`）

- **中文 IME**：新建便签 → 切中文输入法 → 打拼音（看组合中间态）→ 上屏 → 退格删字 → 方向键移动光标。
  - **已知未测**：组合中间态在 GPUI 输入里是否正常显示。这是当前最大的一块空白。
- **缩放**：100% 与 150% 各看一遍列表与编辑器。
- **菜单与属性面板**：禁用项、勾选项、Esc、外部点击关闭。

## 11. 其他平台（如你有 macOS / Linux 机器）

- **macOS**：Retina（scale 2.0）下 Tabs 指示条粗细、分隔线是否清晰；窗口缩放时 Popover 是否跟着重定位。
- **Linux**：Wayland 与 X11 下浮层定位、tooltip 翻转、菜单子面板位置。
