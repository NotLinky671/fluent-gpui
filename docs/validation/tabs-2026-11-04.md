## 设计与取舍

- **焦点模型**：整条 strip 是一个 focus stop，方向键移动选中项（Fluent 的自动激活）。代价是每个 tab 本身不是 tab stop；这样做与库内 `Menu` 的模型一致，也避免为 N 个 tab 各建一个 `FocusHandle`。**与严格 roving tabindex 的差异已记录，未做**。
- **指示条**：tab 的绘制边界由 `on_children_prepainted` 记录到 window keyed state，下一帧用于定位；首次可用时过渡初始化在目标值，所以不会从 0 滑入。边界晚一帧，因此改变选中后同一帧内指示条仍指旧位置——肉眼不可见（过渡本身跨多帧）。
- **hover / pressed**：用局部样式（瞬时），未接入颜色过渡；选中态永远压过 hover。这与 Fluent 一致，但 hover 没有动画，记录为已知差异。
- **受控/非受控**：`selected(..)` 为受控，`default_selected(..)` 为非受控并把索引存 keyed state；`on_change` 两种模式都回调。
- **禁用项不能成为选中**：`selected` 落在禁用项上时退回第一个可用项。
